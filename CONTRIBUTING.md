## Contributions

TensorFEM is an open source project. We welcome contributions via pull requests as well as questions, feature requests, or bug reports via issues. Contact the team with any questions. Contributions must be made under same license at TensorFEM itself - see the LICENSE file.

If you aren't a developer at LLNL, you won't have permission to push new branches to the repository. First, you should create a fork. This will create your own copy of the repository and ensure you can push your changes up to GitHub and create pull requests.

Since TensorFEM is modeled after [BoBa](https://github.com/llnl/BoBa/), please follow the guidelines set forth in the [BoBa Contribution Guide](https://github.com/llnl/BoBa/blob/main/CONTRIBUTING.md), including use of CI testing.

The [BoBa CI script](https://github.com/llnl/BoBa/blob/main/ci.py) should work for this library as well.
