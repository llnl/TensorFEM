
This file shows how to install `mfem`, `boba`, `glvis` and their dependencies.

```
git submodule update --init
```

# Macbook installation

Please use this script, which should work for most macbook installations.

```
./build_mac.sh
```

# LC installation

If you are on an LC system such as Dane, please use our specialized script for LC installation. More details are contained in the script.

```
./build_with_glvis_lc.sh
```
